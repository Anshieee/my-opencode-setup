# Native council and hill-climb adapter

Locally maintained OpenCode2.1.3 adapter, not an unmodified upstream npm plugin. Based on the on-demand independent-advisor design and role guidance in https://github.com/ihxnnxs/opencode-council at 12352148fe6e2581f1e08b53d247401a6fbec5aa (MIT; license included). That package uses legacy @opencode-ai/plugin/config/chat hooks and is not installed. Council of High Intelligence at the pinned source checkout was also inspected for blind deliberation/dissent principles; no persona roster or scripts were copied.

This adapter uses installed official2.1.3 source bb25a2f4a3f3f04d7c344bec0c0574ea3510b3b1: packages/plugin/src/promise/{plugin,tool,command,permission,storage}.ts; packages/core/src/generate.ts; packages/client/src/effect/api/api.ts. Native generate.text is stateless with no tools, no Session stored, and existing model resolution/auth. It does not create council child panes. Results live in the parent tool event and local per-round report. Unlike the upstream legacy package, no TUI settings modal, automatic Git context or proactive policy is installed.

Both existing Go models receive identical frozen evidence in separate blind calls; the parent synthesizes their opinions. They are independent model calls, not human or statistically independent judges. Neither can edit/run tools, see prior scores or other reviewers' responses. Subjective scores remain model judgments. Machine checks are run separately by this plugin with permission.assert before each argv invocation; provider failures, invalid JSON and absent evidence cannot pass.

Hill-climb continuation belongs to the existing /goal plugin, not a new scheduler. Only the controller session explicitly registered by /hill-climb run may evaluate; unregistered subagents cannot start duplicate council loops. The before hook caps create_goal/set_goal/replace_goal duration to the remaining contract time budget, preserving smaller native limits. Stateless reviewer token usage is not attributed to native goal token counters; the wall-clock and round limits bound these extra model calls. Per-session plugin storage holds frozen contract/protected hashes, budget/round and passing certificate. execute.before rejects update_goal complete in a registered hill-climb session unless the last eval passed and declared artifacts/contract/protected files remain unchanged. Unrelated sessions are unaffected. /goal pause and existing goal budgets still apply. Review only declared text artifacts/logs; images/live browser interactions need an external check and supplied evidence. Up to24 artifacts, <=1MB/file and2MB total, excerpts12k/file; selection should fit context and omissions cannot be assumed.

The source is standalone under ~/.config/opencode/plugins/app-council and survives npm cache refreshes. There is no auto-update. ## Anonymous reviewer prompts (2026-11-05)

The local adapter no longer interpolates member IDs, labels, or legacy role labels into model requests. Every seat receives a generic independent-reviewer introduction, its own mandate, and shared task evidence. The jester's challenge mandate is retained without the jester title. No peer roster or peer responses are sent by the adapter; controller-facing reports retain the identity/model mapping for audit. This applies at the shared panel boundary for ordinary council calls, hill-climb scoring, and legacy stored panels. Models can still infer a skeptical assignment from its mandate; arbitrary caller-supplied evidence may itself mention identities. This is prompt isolation, not a guarantee against inference or identity leaks deliberately included in evidence.

This is a locally owned source plugin, not an upstream package setting. Preserve/reapply this panel-boundary change when replacing the adapter, and rerun the saved request-capture tests.
